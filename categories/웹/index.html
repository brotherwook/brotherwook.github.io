[WebSocket] 서버가 브라우저로 실시간 알림 push하기 — msg_type 라우팅과 스택 토스트

서버 이벤트를 브라우저에 실시간으로 띄우고 싶다 서버에서 어떤 일이 생길 때마다(이미지가 하나 만들어졌다든가) 그걸 브라우저 화면에 실시간으로 잠깐 띄우고 싶었다. 화면 구석에 작게, 최신 것이 위로 쌓이면서 몇 초 뒤 사라지는 그런 알림. 폴링(주기적으로 서버에 물어보기)으로도 되지만, “생기는 즉시"가 중요하면 WebSocket이 맞다. 서버가 연결된 브라우저로 먼저 밀어(push) 줄 수 있으니까. 만들면서 정리한 것들을 적어둔다. 하나의 소켓, 여러 종류의 이벤트 — msg_type 라우팅 실시간 채널을 열면 곧 여러 종류의 메시지가 오간다. 이미지 알림, 상태 변경, 하트비트.. 이걸 소켓마다 따로 열지 말고, 하나의 소켓에 메시지 종류를 실어 보내는 게 깔끔하다. 그래서 메시지에 항상 msg_type 필드를 둔다. ...
